# Контекст проекта
Разрабатываю игру на Java + libGDX в стиле Serial Experiments Lain.
Игрок взаимодействует с виртуальной ОС "Copland OS" на компьютере Лейн.

## Текущая архитектура

### Ядро системы:
1. **FileSystem** - управление файловой системой
    - Работает с реальной директорией "./pc" рядом с jar
    - Поддержка файлов и папок

2. **Desktop** - главный менеджер системы
    - Управление окнами и системой в целом
    - наверное стоит использовать Singleton?

3. **ApplicationContainer** - менеджер приложений
    - Многопоточная обработка приложений
    - Рендеринг всех активных приложений

4. **Application** (базовый класс)
    - Абстрактный класс для всех приложений 
    - у него есть наследники - Console, Explorer - приложения, их тоже реализуй

Также же Desktop должен иметь рабочий стол, который находится по пути "./pc/wall.jpg" относительно jar

## Технические требования

- **Язык интерфейса**: Русский (обязательно)
- **Структура проекта**: Gradle Desktop only
- **Путь к файлам**: "./pc/" относительно jar
- **Кодировка**: UTF-8 для русского текста

## Критерии успеха
- [ ] Код компилируется без ошибок
